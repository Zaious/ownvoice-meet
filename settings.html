收音與存檔

檢查時請講者或會場正在說話。檢查用的是上面選的麥克風與增益。

在這台電腦上用聲紋分辨，聲音不會送出去；第一次開啟會下載約 31 MB 的模型。Windows 即時輔助字幕聽不到聲音本身，不能標講者。

「安靜」是指沒有出現新字幕（只錄音時看有沒有聲音）。暫停時不再把聲音送上雲端、不計費，有人說話會自動接上並補上前 2 秒；錄音不受影響。自動結束就像按了 ■ 停止。填 0 表示不暫停或不結束。

每次按「聆聽」都會開一個以日期時間命名的資料夾：每個段落一個錄音檔（WAV，一小時約 115 MB）和一份逐字稿，另有一份整場的 transcript.md。錄音只存在這台電腦，但辨識仍會把聲音送到你選的服務。現場錄音前，請先確認主辦單位的規定。

聽：語音辨識

每小時費用以連續一小時的音訊計。

翻：翻譯與回覆

每小時費用為估算：600 句，每句約 300 個輸入 token、50 個輸出 token。

不用 API key：字幕翻譯、回覆、摘要和「補對照」改用你的 ChatGPT 方案額度（Go、Plus、Pro、Business）。這是 OpenAI 預覽中的功能，語音辨識仍然要另外選。
