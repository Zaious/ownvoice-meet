OwnVoice Meet
English 使用手冊 GitHub

聽得懂會議，用自己的聲音回答。

Understand the meeting. Answer in your own voice.

給英文看得懂、開會時卻一下子想不出怎麼說的人。對方說的英文即時變成字幕和中文；你用中文打想說的話，它變成好唸的英文短句，由你自己說出口。免費、開源。

下載 Windows 版 看它怎麼運作

三個視窗，用得到的才開。

回覆
打中文、按 Enter，大字英文出現，照著唸。它知道會議剛剛在講什麼、你的講稿寫了什麼，名字和術語會用對。在 Zoom、Teams 裡按 Ctrl+Shift+Space 就叫得出來。
字幕
別人說的英文即時出現，每句下面接著中文意思。長句講到一半就先翻，不用等講者停下來。
講稿
簡報稿、準備好的回答和備忘，中英對照、分頁顯示。只寫英文或只寫中文都行，按「補對照」補上另一半。

在研討會會場也能用。

線上會議收電腦的聲音；坐在會場，就改收麥克風。聽、翻、錄、存，一台筆電搞定。

  • 麥克風收音選要用哪支麥克風，離講者遠就調高增益；6 秒的「麥克風檢查」告訴你音量夠不夠。
  • ● 錄音和逐字稿存在你的電腦每句英文、中文和時間都記下來，整場一份，每個場次也各一份。預設不存，要你自己打開。
  • 一個場次一個檔換場次按「新段落」或 Ctrl+Shift+F9；先貼上議程，段落就照議程命名。
  • 網路斷了也不怕錄音和辨識是分開的：會場 Wi-Fi 斷線或 key 出錯，錄音照常進行。網路太差可以只錄音、不辨識。
  • 不會睡著聆聽期間，筆電和螢幕不會自動休眠。
  • 回答提問也用得上輪到你發問或回答時，打中文、唸英文，跟線上會議一樣。

話是你的，聲音也是你的。

它不替你回答。沒有 AI 代寫的回答，也沒有合成語音。說什麼由你決定，也由你自己說出口；OwnVoice Meet 只負責把你的意思變成好唸的英文：每句大約 15 個字以內、用字好發音，語氣和立場照你的。

聽的那一半很多工具都做得到；OwnVoice Meet 的重點在你要開口的那一刻，還有事先準備好的講稿和回答。

常見問題

找不到答案？到 GitHub 問。

要錢嗎？

程式免費、開源（Apache License 2.0）。語音辨識和翻譯用你自己的 API key，費用直接付給 Google、OpenAI 或 Anthropic：最便宜的組合每小時約 0.03 美元，雲端即時字幕加翻譯每小時約 0.57 美元。不想付費可以用 Windows 內建的即時輔助字幕或自己架的 Whisper 辨識。

它會替我回答嗎？

不會。沒有 AI 代寫的回答，也沒有合成語音。你用中文打你想說的意思，它只負責把這個意思變成好唸的英文，由你自己說出口。

需要什麼？

Windows 10 或 11，以及你選的服務的 API key（例如 Gemini 和 Anthropic）。設定裡每個服務旁都有「取得 key」的連結。key 存在 Windows 認證管理員，不會寫進檔案。

錄音和逐字稿存在哪？會上傳嗎？

存檔預設是關的。開啟後，錄音和逐字稿只存在你的電腦（預設在「文件」裡的 OwnVoice Meet 資料夾），不會上傳到作者這邊；但辨識時，聲音會送到你選的語音服務。現場錄音前，請先確認主辦單位的規定。

公司電腦不能安裝程式怎麼辦？

用免安裝版：下載 zip，解壓縮後執行 OwnVoice Meet.exe，不需要系統管理員權限。若公司政策禁止執行下載的程式，或關掉了桌面應用程式的麥克風權限，就無法使用。

Mac 能用嗎？

目前只有 Windows 版。Mac 版在規劃中。

Windows 為什麼說「已保護您的電腦」？

因為程式還沒有程式碼簽章，不代表有問題。按「其他資訊」，再按「仍要執行」。原始碼公開在 GitHub，安裝檔由 GitHub 從原始碼自動建置。

怎麼更新？

安裝版：設定 → 檢查更新 → 更新並重新啟動，會先驗證簽章再安裝。免安裝版請下載新的 zip。程式只有在你按「檢查更新」時才會連到 GitHub。

為一場研討會做的工具。

作者是來自台灣的獨立研究者，英文看得懂，但開會時常常一下子想不出該怎麼說。2026 年 10 月，作者要在 JCDL 2026（ACM/IEEE 數位圖書館聯合會議）的線上 Demo 場發表，當天下午花大約兩小時做出第一版，開著它撐完一個半多小時的場次：別人說話時看字幕和中文，旁邊是中英對照的講稿和準備好的回答，沒準備到的就打中文、唸英文。

之後很多人來要這個工具，OwnVoice Meet 就是為了分享而重做的版本：不需要顯卡，服務也由你挑。

用你自己的帳號，存在你自己的電腦。

會議的聲音只送到你選的語音辨識服務，文字只送到你選的翻譯模型，用的是你自己的 key；作者這邊沒有伺服器，收不到任何東西。程式不做分析，只有在你按「檢查更新」時才會連到 GitHub。選 Windows 即時輔助字幕或自己架的 Whisper，聲音就不會離開你的電腦。

Gemini 的免費層會用你的資料改進產品，請用付費層的 key。有些會議有保密要求，有些地方轉錄談話需要所有人同意，開始前請先確認。
