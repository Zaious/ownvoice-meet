# OwnVoice Meet 使用手冊

聽得懂會議，用自己的聲音回答。這份手冊從安裝講到開會、講稿、省錢與本機執行。專案介紹見 [README](../README.md)。

---

## 1. 安裝

1. 到 [Releases](https://github.com/Zaious/ownvoice-meet/releases) 下載：
   - **安裝版** `…_x64-setup.exe`：只裝給目前使用者，不需要系統管理員權限。之後在設定 → **檢查更新** 就能一鍵更新。
   - **免安裝版** `…_x64_portable.zip`：解壓縮到任何地方，執行 `OwnVoice Meet.exe`。不會自己更新，有新版要重新下載。
2. 程式還沒有數位簽章，Windows 可能顯示「Windows 已保護您的電腦」：按 **其他資訊** → **仍要執行**。
3. 需要 Microsoft Edge WebView2 Runtime：Windows 11 內建；Windows 10 若打不開，請先到微軟官網安裝 WebView2 Runtime。

第一次打開不用任何設定，可以先按 **Demo** 看三個視窗在做什麼。

## 2. 第一次設定（約 3 分鐘）

按主視窗的 **⚙** 開「設定」：

1. **聽：語音辨識**：選一個。不知道選什麼，看第 6 節「省錢」的建議組合。
2. **翻：翻譯與回覆**：選一個。建議從 **Claude Haiku 5.5** 或 **OpenAI gpt-6-luna** 開始（最快、最便宜）。
3. **API key**：在選到的服務旁按 **取得 key ↗**，到該網站建立 key，貼回來。key 存在 Windows 認證管理員，不會寫進檔案。
   - Gemini 請用**付費層**的 key：免費層的資料會被 Google 拿去改進產品。
4. 按 **儲存**。

每個選項都寫著價格、實測速度、強項、注意事項、需要什麼，可以直接比較。

## 3. 開會時怎麼用

1. 打開 Zoom / Teams / Meet，確認會議軟體的**喇叭**設成 Windows 的預設輸出（或「與系統相同」）。OwnVoice Meet 收的是喇叭播放的聲音，**不收你的麥克風**。
2. 按主視窗的 **▶ 聆聽**。狀態列顯示「聆聽中」、音量條在跳，就開始了。
3. 對方說話時，字幕先出現灰字（還在講），講完變白字，下面接著出現中文。
   - 很長的句子講到一半就會先出中文，講完再換成完整翻譯。
4. 想發言時按 **Ctrl+Shift+Space**（在 Zoom 裡也有效）叫出「回覆」視窗，**用中文打你想說的話**，按 Enter，英文大字出現，照著唸。
   - 回覆會參考剛剛的會議內容和你的講稿，名字和術語會用對。
   - 它不會替你作答：打什麼意思，就翻成什麼意思。
5. 結束或休息時按 **■ 停止**（見第 6 節：有些服務連安靜的時間也計費）。

### 視窗操作

| 想做的事 | 怎麼做 |
|---|---|
| 字放大縮小 | 各視窗的 **A− / A+** |
| 背景變透明 | 各視窗的滑桿（只淡化背景，字維持清楚） |
| 只看中文 | 字幕視窗的 **只看中文** |
| 點擊穿過字幕窗，操作下面的會議 | **穿透**；要恢復按 **Ctrl+Shift+F8** 或右下角系統匣圖示 |
| 分享螢幕時別人看不到講稿和回覆 | 預設就是隱藏的；設定 → 畫面 → 「分享螢幕、錄影與截圖時，隱藏…」可以關掉 |

建議擺法：字幕放在螢幕下緣、回覆窗放在**攝影機旁邊**（照唸時看起來像在看對方）、講稿放第二螢幕。

## 4. 講稿與備忘

按主視窗的 **講稿**。講稿會一直保留，下次開啟還在，翻譯和回覆也會參考它。

- **編輯**：直接在視窗裡寫，下方即時預覽，邊打邊存。
- **插入範本**：放一份範例進來改。
- **補對照**：只寫英文 → 自動補上中文意思；**只寫中文 → 自動產生要唸的英文**（中文留著當對照）。已經有對照的行不會被改。
- **開啟講稿…**：讀 `.md` 或 `.txt` 檔。

### 格式（編輯時點「格式說明」也看得到）

| 寫法 | 意思 |
|---|---|
| `# 標題` | 一個分頁（開場、Demo、Q&A，名稱隨你取） |
| `## 小標` | 分頁裡的小標題 |
| `! 提示` | 灰色提示，不用唸（例如「切到第 2 張投影片」） |
| `Q: 問題` | 預先準備的提問 |
| 一般一行 | 要唸的英文（寫中文也可以，按「補對照」轉成英文） |
| `> 中文` | 上一行的中文意思 |
| ` ```copy:名稱 ` … ` ``` ` | 可一鍵複製的區塊（連結、指令） |

格式寫錯也不會讀不到：沒有對照的行一樣會顯示，視窗下方會提醒「幾句還沒有對照」。

真實範例：作者在 JCDL 2026 用的講稿（公開部分）在 [examples/scripts/journal-atlas-jcdl2026.md](../examples/scripts/journal-atlas-jcdl2026.md)。

## 5. 術語表

設定 → **術語表**，每行寫 `中文 = English`，例如 `季度營收 = quarterly revenue`。兩個方向都會照用，英文也會提示語音辨識（對人名、產品名特別有幫助）。

## 6. 省錢

費用分兩塊：**聽**（語音辨識）和**翻**（翻譯與回覆）。翻譯在最便宜那一級每小時只要幾美分，**費用大多在「聽」**。以下價格為官方牌價估算，實際以各家帳單為準；設定 → **用量** 會記錄你自己的實際用量。

### 建議組合（每小時）

| 組合 | 聽 | 翻 | 約每小時 | 適合 |
|---|---|---|---|---|
| **最省** | Windows 即時輔助字幕（免費，在電腦上辨識） | Claude Haiku 5.5 或 gpt-6-luna | **US$0.03** | Windows 11；有灰字；辨識品質略遜雲端 |
| **有 NVIDIA 顯卡** | 本機 Whisper（免費） | 同上 | **US$0.03** | 音訊不出電腦（見第 7 節） |
| **雲端、不需要灰字** | OpenAI gpt-4o-mini-transcribe（US$0.18） | 同上 | **US$0.21** | 一句講完才出字 |
| **雲端、有灰字** | Gemini 3.5 Transcribe Live（US$0.54） | 同上 | **US$0.57** | 最順的即時字幕 |
| 雲端、有灰字 | OpenAI gpt-live-transcribe（US$1.02） | 同上 | US$1.05 | 已經用 OpenAI 的人 |

實例：作者在 JCDL 2026 一整天（含 1.5 小時場次與開發測試）的 Claude Haiku 5.5 翻譯費用是 **0.11 美元**；那時語音辨識跑在自己的顯卡上，不用錢。

### 省錢技巧

1. **翻譯選最快一級**：Claude Haiku 5.5、gpt-6-luna（每小時約 0.03 美元）。Sonnet 5.5、gpt-6.1-sol 約貴 20 倍，即時字幕通常用不到；Gemini 3.8 Flash 實測每句 4–7 秒，對字幕太慢。
2. **不開會就按停止**：Gemini Live 連**安靜的時間**也照秒計費；OpenAI gpt-live-transcribe 只送有人講話的部分。休息、等人時按 ■ 停止。
3. **講稿長沒關係**：講稿每次都會一起送出，但走「快取讀取」，費用約一般輸入的一成。JCDL 那天 557 萬個輸入 token 只花 0.11 美元，大部分就是講稿。
4. **長句先翻**會多幾次翻譯呼叫（用量裡標示 `early`），每小時多幾美分；想再省可以選不出灰字的辨識。
5. **用 ChatGPT 帳號翻譯**（非官方、風險自負）：見 [docs/LOCAL.md](LOCAL.md) 的 openai-oauth 一節，翻譯可以不用 OpenAI API key。
6. **Gemini 免費層**：不付費也能用，但會議內容會被 Google 拿去改進產品。要省錢還是要隱私，由你決定；會議有保密要求就用付費層。

## 7. 本機執行（不上雲端）

在設定裡選「本機 Whisper」或「本機模型」，填伺服器網址和模型名稱，按 **測試連線** 確認。

- **本機 Whisper**：repo 附了一個最小伺服器 `scripts/local_whisper_server.py`（需要 Python 與 `pip install faster-whisper`；有 NVIDIA 顯卡最快，沒有也能用 CPU）。
  ```
  python scripts/local_whisper_server.py --model large-v3 --device cuda --port 8790
  ```
  設定填 `http://127.0.0.1:8790/v1`。作者在 RTX 3090 上實測：5 秒的句子，第一次 2.9 秒（載入模型），之後約 0.7 秒。
- **本機模型（翻譯）**：vLLM（`http://localhost:8000/v1`）、Ollama（`http://localhost:11434/v1`）都可以；**測試連線並列出模型** 會列出伺服器上的模型讓你選。小模型的繁中與台灣用語品質差異大，請先試幾句。

完整說明：[docs/LOCAL.md](LOCAL.md)。

## 8. Windows 即時輔助字幕（實驗功能）

免費、在電腦上辨識、不需要 key，限 Windows 11 22H2 以上。第一次使用需要三個步驟，設定裡選它之後會出現清單，每步都有按鈕帶你到要按的地方，做完自動打勾：

1. 同意 Windows 在電腦上處理語音。
2. 下載英文語音檔。
3. 把即時輔助字幕切成英文（App 會自動處理）。

沒做完就按「聆聽」，App 會提醒你回設定照步驟做。

## 9. 常見問題

| 狀況 | 怎麼辦 |
|---|---|
| 沒有字幕、音量條不動 | 會議軟體的喇叭要是 Windows 預設輸出；換了耳機要先按停止再按聆聽 |
| 字幕有、中文沒有 | 看中文那行的錯誤訊息：多半是翻譯的 key 沒填、額度不足，或帳號沒開那個模型（例如 429「0 requests per minute」是 workspace 的限制） |
| 「請先到設定填 … 的 API key」 | 你選的辨識或翻譯服務還沒有 key |
| 快捷鍵沒反應 | 可能被其他程式占用，狀態列會顯示；關掉占用的程式後重開 |
| 字幕跳成別的語言 | 設定 → 語言 填 `en-US`（留空是自動偵測） |
| 開會超過 10 分鐘會斷嗎 | Gemini Live 單次連線最多 10 分鐘，App 會在停頓時自動重連，不用管 |
| 想看自己花了多少 | 設定 → 用量（這次開啟／今天／本月） |

## 10. 隱私

會議聲音會送到你選的語音辨識服務，文字送到你選的翻譯模型，用的是**你自己的帳號**。有些會議有保密要求，有些地方轉錄談話需要所有人同意，開始前請先確認。選本機 Whisper 或 Windows 即時輔助字幕，聲音就不會離開你的電腦。
